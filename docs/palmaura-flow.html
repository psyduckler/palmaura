Flow overview

The app is intentionally linear until the first completed reading. After onboarding, the main loop is capture → review → generation → reveal → explore privately. Share/export is intentionally out of scope for now.

System notes

The current app shape is clean: durable profile lives outside the generation flow, the palm photo path is one-shot, and results stay private while share/export is paused.

Persisted state

  • disclaimerAccepted gates legal/privacy copy.
  • onboarding answers store birthday, energy/gender, dominant hand.
  • last reading powers revisit/palm-map/report branches.

Backend boundary

  • Review screen prepares JPEG/base64 payload.
  • Loading screen requests reading and line geometry.
  • Result screens consume aura, archetype, guidance, ritual, and line map.

Product critique

  • The map is the trust surface; it should remain soft unless line detection is reliable.
  • Share/export is deliberately paused; do not surface share cards, system share, or map export in this version.
  • The first-run ceremony can be slower; returning readings should stay tight.
