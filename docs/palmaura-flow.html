Implementation notes

Backend payload

Current request sends clientRequestId, deviceId, appVersion, locale, imageBase64Jpeg, and onboarding profile/session context to /api/read. The backend no longer asks for or returns palm-line coordinates.

Visual truth

Palm map now means “clean photo + symbolic lenses,” not precise crease tracing. This avoids the bad uncanny overlay problem while preserving the product metaphor.

Review focus

The biggest UX decision is whether the question step should precede camera capture every time, or whether camera capture should become the primary action with the question tucked into review/loading.

Next build items

Likely remaining work: paywall/membership rules, reading library, share card, onboarding compression, App Store privacy text, and final QA on a physical iPhone camera.
